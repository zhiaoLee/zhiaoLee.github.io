- **作者**：Xuweiyi Chen、Jin Yao、Linzhan Mou、Lei Gong、Di Liu、Cheng Zhang、Ziqiao Ma、Sihan Xu、Adam W. Harley、Shengyi Qian、Zezhou Cheng

### 快速理解

- **研究背景**：点对应要求跨帧对同一物理表面点做像素级定位，即便外观改变或点消失后重现，这比物体级识别难得多，因此即使是已在检测、视频识别上超越专家模型的通用VLM也难以胜任。

- **结果与结论**：AgenTAP在点定位与可见性预测上均超越专家视觉模型；在采样的重现点上其预测接近人类标注一致性；将EgoTAP-4D加入D4RT训练可提升平均3D追踪性能。

**中文摘要**：通用视觉-语言模型（VLM）已在物体检测、视频识别等诸多领域超越了专家视觉模型。然而，点对应（point correspondence）对VLM而言是出了名的难题，因为它超出了物体级识别的范畴：它要求跨观测对同一物理表面点进行像素级定位，即使该点外观发生变化、或者消失后又重新出现。本文提出AgenTAP，一个基于VLM的智能体，它能直接预测点的坐标和可见性，并主动地在视频上进行推理。从自身给出的估计出发，该智能体自主选择要检查的内容，并利用所得证据验证点的身份、细化其预测。搭载GPT-6 Astra时，AgenTAP在点定位和可见性预测两项任务上均超越了专家视觉模型，且无需任何针对对应任务的专门微调。我们进一步利用AgenTAP在点消失后重新识别物理点并 reconnect 碎片化的轨迹，构建了EgoTAP-4D——一个来自长时长真实第一人称（egocentric）视频的3D点轨迹数据集。在采样的重新出现的点上，其预测接近人类标注者之间的一致性水平；将EgoTAP-4D加入D4RT的训练还能提升平均3D追踪性能。

## 3. Agentic LongLive：面向长视频生成的异步智能体记忆

- **英文标题**：Agentic LongLive: Asynchronous Agentic Memory for Long Video Generation
- **作者**：Shaoteng Liu、Shuai Yang、Wei Huang、Luozhou Wang、Song Han、Yukang Chen
- **分类**：cs.CV
- **发布时间**：2026-11-25 18:54:03 UTC
- **链接**：[原文摘要](https://arxiv.org/abs/2611.34907v1) · [PDF](https://arxiv.org/pdf/2611.34907v1)
- **匹配方向**：LLM + Agent

### 快速理解

- **研究背景**：实时自回归视频生成器虽然能流式生成数分钟视频并接受新提示词，但在长交互故事中难以保持人物、物体和场景一致。现有的智能体记忆系统只适用于离线多镜头生成，因为它们需要预先读完整剧本、提前规划镜头并重生成失败镜头，直播流场景无法满足这些前提。
- **核心创新**：提出异步智能体记忆架构：记忆智能体运行在独立 GPU 上，只读已揭示的提示词而不读生成视频，因此记忆与生成解耦、视频无需等待，且视频错误不会污染记忆。记忆决策由强化学习训练的小语言模型完成，使用以最终视频结果校准的图像奖励，使其能在未知下一提示词时提前决定记什么。
- **方法概览**：记忆智能体为每个人物、物体和场景维护文本状态与演化图像的实体记忆，据此合成一张全局图像和一张逐镜头记忆图像，由辅助 GPU 在下一镜头开始前预填充进生成器的注意力汇聚中，并为提及实体的提示词生成实体卡片。
- **结果与结论**：在新基准 LongStory-Online（25 个故事、857 个镜头，逐镜头揭示）上，相比基础生成器 LongLive-2.0，持久状态准确率提升 26.3 个百分点、主角身份一致性提升 44.9、重访场景一致性提升 40.4，而 H100 上仅增加约 1% 生成时间；完整系统在 8×B200 节点、BF16 下以 34.3 FPS 实现快于实时的流式生成，14 分钟故事画质稳定，并在两个 MiniMax-H3 生成器上提升身份一致性，其中 LongLive-H3 也能实时运行。
- **一句话 takeaway**：这是首个由 LLM 智能体维护文本与图像记忆的实时视频生成器，表明将记忆计算异步移出关键生成路径可以在几乎不增加延迟的前提下显著改善长视频的角色与场景一致性。

**中文摘要**：实时自回归视频生成器可以流式输出长达数分钟的视频并随时接受新提示词，但难以在一段长交互式故事中保持人物、物体和场景的一致性。智能体系统虽能为离线多镜头生成提供这种记忆能力，但它们需要预先读取完整剧本、在生成每个镜头前做好规划、并重新生成失败镜头，而直播流式场景不允许这样做。我们提出 Agentic LongLive，一种用于长视频生成的异步智能体记忆机制。一个运行在独立 GPU 上的记忆智能体只读取迄今已揭示的提示词，从不读取已生成的视频，并为每个人物、物体和场景维护文本状态与演化中的图像。基于该实体记忆，它合成一张全局图像和一张逐镜头记忆图像，由一块辅助 GPU 在下一个镜头开始前预填充（prefill）进生成器的注意力汇聚（attention sink）中，同时为提及这些实体的提示词撰写实体卡片，因此视频生成从不因记忆而等待，且视频中的错误也不会被写回记忆。一个小型语言模型通过强化学习训练，并使用以随后视频结果校准的图像奖励，在下一个提示词尚未知晓时决定要记住什么。在新的 LongStory-Online 基准（25 个故事、857 个镜头，每次只揭示一个镜头）上，Agentic LongLive 将其基础生成器 LongLive-2.0 的持久状态准确率提升了 26.3 个百分点，主角身份一致性提升 44.9，重访场景一致性提升 40.4，而在 H100 上仅增加约 1% 的生成时间。完整系统在单台 8×B200 节点上以 BF16 精度运行生成器时，流式生成速度快于实时（34.3 FPS），在 14 分钟的故事中保持图像质量稳定，并在两个 MiniMax-H3 生成器上提升了身份一致性，其中 LongLive-H3 在该机制下同样能实时运行。据我们所知，这是首个由 LLM 智能体维护文本与图像记忆的实时视频生成器。

- **作者**：Yuxiang Lai、Jike Zhong、Yu-Jhe Li、Lan Wang、Chengzhi Liu、Youbao Tang、Ming Li、Xi Xiao、Xiaofeng Yang、Liang Zhao、Zheda Mai、Ruixi Fan

**中文摘要**：近期的视觉-语言模型（VLM）可以充当机器人操作智能体，理解多样场景并通过策略代码和工具控制机器人。然而，即使进行扩展推理，它们对三维夹爪位姿的预测仍然很差，难以完成精细操作。视觉-语言-动作（VLA）模型和世界-动作模型（WAM）则相反：它们能在训练过的任务上执行快速、平滑的控制，但在域偏移下、或当任务需要长时程记忆与推理时就会失败。因此，智能体机器人通过策略Harness将VLM的推理与感知能力和精确的VLA/WAM控制结合起来。然而Harness设计涉及数千种配置，使用相同的模型成功率也会相差数十分。此外，即使只测试一种设计也需要数千次rollout，API和GPU成本高昂，因此以往工作往往从少数备选方案中选定单一设计。为指导Harness设计，我们在八个仿真基准、六个VLM和15个VLA/WAM检查点上评估了超过47万次rollout。七项受控研究表明，有效的Harness必须同时适应VLM和VLA/WAM两者的能力。我们的发现明确了VLM的策略代码需要什么样的结构、VLA操作在何处需要工具和策略代码的帮助，以及在测试时何时引入VLM。参考方案X-Harness表明，这些发现可以在不更新权重的情况下组合起来，在记忆、推理和域偏移场景中将基础策略的成功率最多提升+42.8个百分点。

## 5. TASK记忆：超越纯文本记忆，结合激活引导与知识编辑对抗记忆幻觉

- **英文标题**：TASK Memory: Beyond Text-Only Memory with Activation Steering and Knowledge Editing against Memory Hallucination
- **作者**：Jinkun Zhao、Wenjun Wu
- **分类**：cs.AI
- **发布时间**：2026-11-25 17:30:37 UTC
- **链接**：[原文摘要](https://arxiv.org/abs/2611.34762v1) · [PDF](https://arxiv.org/pdf/2611.34762v1)
- **匹配方向**：LLM + Agent

### 快速理解

- **研究背景**：LLM智能体日益依赖外部记忆，但即使正确记忆已被检索进提示词，模型仍会忽视记忆、将其套用到无关实体上，或在新旧版本事实间混淆，产生“使用时的记忆幻觉”。作者对五个开源模型的分析表明，这类幻觉源于参数化知识与外部记忆之间的冲突，发生率分别可高达46%、24%（结合权重编辑时49%）和53%。
- **核心创新**：提出TASK记忆框架，将文本笔记、可移除的知识编辑与一对不存储内容的激活引导向量绑定到同一模型内地址，把“记忆的内容”“记忆的寻址”和“是否采用记忆的逐查询决策”解耦，从而统一应对记忆忽视、记忆误用与版本混淆三类使用时幻觉。
- **方法概览**：每条记忆由三部分共享一个模型内地址：文本承载事实内容；一个可移除的知识编辑以其主语键充当地址并支持多跳组合；一对激活引导向量在每次查询时决定模型采用外部记忆还是保留自身答案。方法在冻结模型上实现，并采用预注册、只测一次的评估协议，在五个开源模型（8B-27B、四个家族）上与BM25 RAG及三种近期上下文引导方法对比。
- **结果与结论**：在全部十个模型-数据集组合中，记忆忽视型幻觉降至不超过1.5%，邻居误用从39.2%降至7.5%（CounterFact综合提升10.8个百分点）；300条记忆库较BM25 RAG高16.4个百分点且优势在3000条记忆时保持，无需事实ID即可解决事实修订，MQuAKE多跳准确率提升7.5个百分点；23项跨模型比较中21项显著，并在10个组合中的9个上胜过三种近期上下文引导方法。
- **一句话 takeaway**：记忆幻觉的瓶颈不在于“检索不到”而在于“用不对”，因此为文本记忆配备可寻址、可开关的使用机制（知识编辑定址加引导向量决策）比单纯改进检索更关键。该设计在不改动冻结模型的前提下让智能体能可靠地采用、修订和组合外部记忆，对构建可信的长期记忆智能体具有直接借鉴意义。

**中文摘要**：大语言模型智能体越来越依赖外部记忆，但它们仍会在所记内容上产生幻觉。通常正确的记忆已被检索出来并放入提示词中，但模型的回答却与之矛盾，或者记忆被用到了错误的问题上。我们将这类现象称为“使用时的记忆幻觉”。在五个开源模型上，我们发现这类幻觉源于参数化知识与外部记忆之间的冲突，并呈现三种形态：记忆忽视（memory-ignoring），即模型回到其权重中存储的过时事实（最高占查询的46%）；记忆误用（memory-misapplying），即将记忆错误地归因到无关实体上（最高24%，当检索与权重编辑相结合时达49%）；以及版本混淆（version confusion），即当新旧两个版本的事实同时存储时，53%关于已修订事实的回答给出了已被取代的旧值。我们提出TASK记忆，它超越纯文本记忆，将文本笔记与激活引导（Activation Steering）和知识编辑（Knowledge Editing）相结合，三者共享同一个模型内地址。文本承载内容；一个可移除的知识编辑通过其主语键提供地址，并支持多跳组合；一对引导向量逐查询地决定模型是采用该记忆还是保留自己的答案，这些向量不存储任何内容，只控制文本记忆的使用方式。在冻结模型上、采用预注册且只测一次的评估协议，TASK在全部十个模型-数据集组合中将记忆忽视型幻觉降至最高1.5%，并将邻居误用从39.2%降至7.5%（在CounterFact上综合提升10.8个百分点）。在300条记忆的库上，它相比BM25 RAG提升16.4个百分点，且该优势在3000条记忆时依然保持；无需事实ID即可解决事实修订问题，并在MQuAKE上增加7.5个百分点的多跳准确率。23项跨模型比较（8B-27B、四个模型家族）中有21项达到显著，且TASK在十个模型-数据集组合中的九个上优于三种最新的上下文引导方法。

## 6. SOLVE：稀疏有序的关键位姿（Keyposes）使 LLM 智能体成为通用且高效的机器人操作器

- **英文标题**：SOLVE: Sparse, Ordered Keyposes Make LLM Agents Versatile and Efficient Robot Manipulator
- **作者**：Xiang Li、Hongyu Zhou、Ya-Li Li、Tao Li、Rui Zhang、Junjie Lai、Weihua Zhang、Shengjin Wang
- **分类**：cs.RO, cs.CV
- **发布时间**：2026-11-25 17:25:17 UTC
- **链接**：[原文摘要](https://arxiv.org/abs/2611.34750v1) · [PDF](https://arxiv.org/pdf/2611.34750v1)
- **匹配方向**：LLM + Agent

### 快速理解

- **研究背景**：现有的 LLM 机器人操作智能体通常采用逐步密集控制的方式，每次决策只输出一小步动作，导致推理调用频繁、成本高昂，并受到工具链瓶颈的制约。同时，作者观察到遥操作演示（如 DROID 数据集）本身具有高度稀疏性，大多数演示可以压缩为少数关键位姿。
- **核心创新**：提出让多模态 LLM 智能体一次性输出稀疏、有序的 6-DoF 末端执行器关键位姿序列、由运动规划器插值执行的新范式，且关键位姿的数量与间距由智能体自主决定，从而同时支持长距离快速运动与精细操作。此外，智能体通过稀疏深度查询（多视角三角化、立体、单目深度等带噪声来源）自主完成关键位姿的几何定位并容忍其噪声，还能通过反思自身 rollout、为每个任务蒸馏少量规则来持续改进，全程无需训练。
- **方法概览**：SOLVE 采用“写关键位姿—观察结果—写下一组关键位姿”的循环：LLM 每次调用生成一组稀疏有序的 6-DoF 末端执行器关键位姿，底层运动规划器在关键位姿之间插值执行。关键位姿的空间位置通过向多视角三角化、立体匹配或单目深度等噪声来源发起稀疏深度查询获得，由智能体自身处理查询噪声；执行后智能体反思 rollout 并提炼每任务的少量规则以迭代提升表现。
- **结果与结论**：SOLVE 在 RoboDojo 上取得 74.5%、在 RoboLab 上取得 84.5% 的最先进成功率，平均每个 episode 成本仅 1.7 美元，较以往密集控制智能体策略便宜 12 倍；在真实机器人上，同一智能体对 16 个零样本挑战任务取得 88% 成功率（85 个 episode 成功 75 个）。
- **一句话 takeaway**：将 LLM 的操作决策粒度从密集动作提升到由智能体自主决定间距的稀疏关键位姿，可以在保持细粒度操作能力的同时大幅降低推理成本（12 倍）并达到 SOTA 成功率。这一结果也说明真实演示数据本身高度可压缩，结合运动规划插值与噪声深度 grounding，无需训练的 LLM 智能体即可在真实机器人上完成多样化的零样本任务。

**中文摘要**：LLM 智能体在机器人操作领域取得了显著进展，但仍面临推理成本高、需要逐步密集控制以及工具瓶颈等问题。我们提出 SOLVE，一种无需训练、通用且高效的智能体策略：多模态 LLM 智能体在每次调用中写出一组稀疏、有序的 6 自由度末端执行器关键位姿（keyposes），观察执行结果后再写出下一组，并由运动规划器在关键位姿之间进行插值。智能体自行决定关键位姿的数量与间距，从而兼顾快速的长距离运动和细粒度操作。这种粒度与遥操作演示数据的稀疏性相吻合：DROID 数据集中的大多数演示可以被压缩为少数几个关键位姿，而非密集的动作序列。SOLVE 通过稀疏的深度查询来为关键位姿提供几何基础，这些查询由带噪声的来源回答，例如多视角三角化、立体匹配或单目深度估计，噪声问题由智能体自身处理。SOLVE 还能从执行反馈中改进：它对自身的 rollout 进行反思，并为每个任务提炼出少量规则。SOLVE 在 RoboDojo 上达到 74.5%、在 RoboLab 上达到 84.5% 的最先进性能，平均每个 episode 成本仅为 1.7 美元，比以往的密集控制智能体策略低 12 倍。在真实机器人上，同一个智能体在 16 个具有挑战性的零样本任务上取得了 88% 的成功率（85 个 episode 中成功 75 个）。项目主页为 https://serenos.github.io/solve-website。

## 7. 当世界模型可读时，我们还需要强化学习吗？

- **英文标题**：Do We Still Need Reinforcement Learning When We Can Read the World Model?
- **作者**：Mingchao Zhang、Miduo Cui、Kangze He、Yuanjun Li、Dapeng Li、Ce Zhang、Chuanchen Luo、Xue Yan、Mingzhe Xing、Zhumin Chen、Hangyu Mao、Bin Zhang、Zhiwei Xu
- **分类**：cs.LG, cs.AI, cs.MA
- **发布时间**：2026-11-25 16:29:37 UTC
- **链接**：[原文摘要](https://arxiv.org/abs/2611.34656v1) · [PDF](https://arxiv.org/pdf/2611.34656v1)
- **匹配方向**：LLM + Agent

### 快速理解

- **研究背景**：强化学习在序贯决策任务上表现出色，但通常需要大量交互试错；基于模型的强化学习虽然利用世界模型减少样本消耗，但世界模型一般只用于规划或策略优化的辅助工具。
- **核心创新**：提出了一种新范式：让基于LLM的编程智能体直接阅读可读的世界模型（环境源代码），将其中的环境知识推理并转化为可执行的控制策略，从而完全绕过针对特定任务的强化学习训练。
- **方法概览**：编程智能体检查环境源代码以理解其动态规律，合成可执行的决策规则作为策略，并通过在线反馈或离线数据对策略进行迭代式改进，同时辅以无源代码访问和有源代码访问的消融对比。
- **结果与结论**：在多个不同决策基准上，综合出的策略以大幅减少的经验量达到或超越传统强化学习方法；分析显示所得决策规则具有可解释性并能随反馈演化，且消融实验证实读取源代码（可读世界模型）带来了明显优势。
- **一句话 takeaway**：当环境动态以可读形式（源代码）呈现时，LLM智能体可以直接推理并合成高质量策略，大幅降低对试错式交互的依赖，这促使我们重新思考特定任务强化学习训练是否必不可少。

**中文摘要**：强化学习在序贯决策中取得了显著成功，但学习有效策略往往需要大量的交互经验。基于模型的强化学习通过利用世界模型来缓解这种依赖，而世界模型通常被用于支持规划或策略优化。本文研究了一种替代性范式：由大语言模型（LLM）驱动的自主编程智能体通过对可读的世界模型进行推理，直接综合出控制策略。这些智能体通过检查环境的源代码，将环境知识转化为可执行的决策规则，并利用在线反馈或离线数据迭代地改进其策略，全程无需针对特定任务的强化学习训练。在多个多样化决策基准上的实验表明，所综合的策略达到或超过了传统强化学习方法，且所需的经验量大幅减少。进一步的分析揭示了这些可解释的决策规则以及它们如何通过反馈驱动的改进而演化。与无法访问源代码时生成的策略的对比，以及在具有挑战性条件下的实验，进一步证明了可读世界模型的益处。这些发现表明，直接的策略综合可以降低对试错法的依赖，从而对特定任务强化学习训练的必要性提出了挑战。

## 8. ZeroHero：从零开始训练小型语言智能体

- **英文标题**：ZeroHero: Training Small Language Agents from Scratch
- **作者**：Nikita Sorokin、Zoya Volovikova、Alexey Skrynnik、Aleksandr Panov
- **分类**：cs.AI
- **发布时间**：2026-11-25 16:20:13 UTC
- **链接**：[原文摘要](https://arxiv.org/abs/2611.34635v1) · [PDF](https://arxiv.org/pdf/2611.34635v1)
- **匹配方向**：LLM + Agent

### 快速理解

- **研究背景**：大型预训练语言模型在交互式任务上表现出色，但专门化语言智能体所需的模型容量尚不明确。若小规模模型足以胜任，将显著降低此类智能体在特定环境中部署的成本。
- **核心创新**：提出 ZeroHero 框架，证明参数量不足 5000 万的小型语言智能体可以完全从零训练，而非依赖大型预训练模型。其核心创新是在 PPO 后训练中引入“推理对齐”，在环境奖励之外对智能体生成的推理语言施加专家监督。
- **方法概览**：先由大语言模型在各环境中充当专家并收集其成功轨迹，据此预训练小型模型在给定交互历史下预测专家回复；随后用 PPO 在智能体自身交互上后训练，并以推理对齐将专家对其生成语言的监督与环境奖励相结合。在 Crafter（解读文本观测并先生成推理再行动）、WebShop（将购物指令转为搜索查询）和 Alfworld-Dialogue（提问澄清并据此指导家务操作）三个多步环境中进行评估。
- **结果与结论**：摘要未给出具体数值结果，但报告小型智能体在 WebShop 上接近专家水平，并在 Crafter 训练 rollout 和留出的 Alfworld-Dialogue 任务上超越了各自的演示专家。
- **一句话 takeaway**：针对特定交互环境，参数量不足 5000 万、从零训练的小型语言智能体通过专家轨迹蒸馏加带推理对齐的强化学习，即可在需要语言理解与生成的高层次多步任务上接近甚至超越其大模型专家，说明专门化智能体未必需要大模型容量。

**中文摘要**：大型预训练语言模型为交互式任务提供了强大的策略，但一个专门化的语言智能体究竟需要多大的模型容量？我们提出 ZeroHero，一个从零开始训练小型语言智能体（SLA）的框架。在每个环境中，由一个大语言模型充当专家，我们收集其成功的轨迹。我们对每个参数量不足 5000 万的 SLA 进行预训练，使其在给定交互历史的条件下预测专家的回复。随后我们使用近端策略优化（PPO）在智能体自身的交互数据上对其进行后训练。在后训练期间，推理对齐在环境奖励之外进行补充，即在智能体随动作一并生成的语言上施加专家监督。我们在三个行动既需要理解语言又需要生成语言的多步环境中评估这些智能体。在 Crafter 中，智能体解读文本观测并在行动前生成推理；在 WebShop 中，它们将购物指令转化为搜索查询；在 Alfworld-Dialogue 中，它们提出澄清性问题，并利用回答来指导家务操作。这些智能体在 WebShop 上接近专家水平，并在 Crafter 训练 rollout 和留出（held-out）的 Alfworld-Dialogue 任务上超越了各自的演示专家。交互式演示见 https://zoyav.github.io/-ZoyaV-zerohero-demo。
